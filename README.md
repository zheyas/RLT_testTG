# Анализ данных о владельцах компаний

Данный проект выполняет очистку, нормализацию и анализ данных о владельцах компаний из файла `corporate_links_raw.xlsx`. Скрипт написан на Python с использованием библиотек `pandas`, `numpy`, `openpyxl`.

## Задача

1. **Очистка и нормализация**:
   - Приведение ФИО к формату `Фамилия И.О.`
   - Удаление кавычек и лишних пробелов в названиях компаний
   - Преобразование ИНН в строковый тип, выделение записей с отсутствующим ИНН
   - Приведение долей владения к процентам (`0.5` → `50%`)
   - Унификация дат в формат `YYYY-MM-DD`

2. **Анализ данных**:
   - Поиск компаний, где суммарная доля владельцев превышает 100% на конкретную дату
   - Выявление компаний, в которых состав владельцев или их доли менялись во времени
   - Поиск владельцев, участвующих более чем в одной компании

3. **Формирование отчёта**:
   - Сохранение результатов в Excel-файл с несколькими листами
   - Краткий вывод в консоль

## Требования

- Python 3.7+
- Установленные библиотеки: `pandas`, `numpy`, `openpyxl`

Установка зависимостей:
```bash
pip install pandas numpy openpyxl
```

## Использование

1. Поместите исходный файл `corporate_links_raw.xlsx` в ту же папку, что и скрипт `main.py`.
2. Запустите скрипт:
   ```bash
   python main.py
   ```
3. После выполнения в консоли отобразятся краткие результаты, а в папке появится файл `corporate_analysis_result.xlsx`.

## Выходной файл `corporate_analysis_result.xlsx`

Содержит следующие листы:

- **Очищенные_данные** – все записи после нормализации и удаления дубликатов.
- **Отсутствует_ИНН** – записи, где поле ИНН пустое.
- **Сумма_долей_>100** – компании и даты, где сумма долей превышает 100%.
- **Изменения_в_компаниях** – компании с несколькими датами, описание изменений состава и долей.
- **Владельцы_>1_компании** – владельцы, встречающиеся более чем в одной компании.
- **Отсутствует_доля** – записи, где не указана доля владения.

## Анализ сомнительных данных и возможных ошибок источников

На основе обработанных данных выявлены следующие проблемы:

- **Превышение 100%** – в ООО «Альфа» на 2020-06-05 сумма долей 110% (дублирование или неверные цифры).
- **Неполнота данных** – в ООО «Лютик» после изменений «исчезло» 40% компании (нет данных о продаже).
- **Смена владельца без промежуточных записей** – в ООО «Ромашка» полная замена владельца за 3 дня.
- **Отсутствие обязательных реквизитов** – нет ИНН у Кузнецовой, нет доли у Лебедева.
- **Множественное участие одного лица** – Иванов И.И. в трёх компаниях (возможно, разные люди с одинаковыми инициалами).

**Возможные ошибки источников**:
- Разные форматы данных от Kommersant, RBC, Forbes.
- Ошибки ручного ввода или автоматического парсинга (дубликаты, пропуски).
- Неполнота публикуемых отчётов (не все сделки раскрываются).
- Отсутствие ИНН затрудняет точную идентификацию компаний.
- Разнородные форматы дат могли привести к искажению хронологии.
Подробнее в Описание_анализа.docx

## Примечания

- Скрипт автоматически удаляет явные дубликаты (одинаковые ФИО+компания+дата+доля).
- Все даты приводятся к единому формату, но исходная неопределённость (день/месяц) может сохраняться.
